**iPixSoft Flash ScreenSaver Maker** (currently **v4.9.0**) is a Windows desktop utility by iPixSoft Studio designed to turn digital photos and background audio into animated Windows screensavers. It functions as a streamlined edition of iPixSoft Video Slideshow Maker focused exclusively on generating screensaver files.

### Core Features

* **Photo & Audio Import:** Supports adding up to 500 images per project with basic built-in editing (brightness, contrast, cropping, and filters) alongside MP3, WAV, or WMA background music.
* **Templates & Transitions:** Includes 35+ pre-designed templates (with 21 additional free templates available from iPixSoft) and 70+ customizable transition effects.
* **Decorations & Branding:** Offers 130+ animated clipart elements, 100+ sound effects, support for custom SWF/PNG/JPG overlays, clickable slide hyperlinks, and custom Intro/Credit screens.
* **Direct Deployment:** Publishes `.SCR` files straight into your Windows system directory for immediate selection in Windows Screen Saver Settings, or packages them as shareable `.EXE` installers.

### Modern Windows Compatibility Note

Because iPixSoft Flash ScreenSaver Maker relies on legacy Adobe Flash (`.SWF`) rendering components, generated `.SCR` or `.EXE` screensavers may require older Flash Player ActiveX runtimes or compatibility settings to display properly on modern Windows 10 and Windows 11 systems.
